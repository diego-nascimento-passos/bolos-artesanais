# 🍰 Bolos Artesanais

Projeto desenvolvido durante meus estudos de **Análise e Desenvolvimento de Sistemas** e da minha jornada de aprendizado em **Desenvolvimento Web**.

A página apresenta informações sobre bolos artesanais, massas, recheios, tamanhos, valores, adicionais, formas de pagamento e encomendas.

## 📋 Sobre o projeto

O **Bolos Artesanais** foi desenvolvido como um projeto prático para aplicar os conhecimentos adquiridos durante os estudos de **HTML5**.

A página foi estruturada para apresentar as informações dos produtos de forma organizada, incluindo tabelas de preços, imagens, links de contato e um formulário para solicitação de encomendas.

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/diego-nascimento-passos/bolos-artesanais.git
```

### 2. Acesse a pasta

```bash
cd bolos-artesanais
```

### 3. Abra o projeto

Abra o arquivo:

```text
Bolos Artesanais/index.html
```

no navegador.

Também é possível utilizar o **Visual Studio Code** e uma extensão como o **Live Server** para visualizar o projeto durante o desenvolvimento.
